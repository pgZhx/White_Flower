# 项目操作规范（必须遵守）

> 本文档用于记录本项目的重要环境约束和操作边界。

## 1. 服务器定位

- 当前实验室服务器是导师租用的科研项目服务器。
- 本项目只能将其作为**开发环境**。
- 禁止在当前实验室服务器上长期运行生产后端服务。
- 未来购买独立小云服务器后，再将服务正式部署到该服务器。

## 2. 账号性质

- 当前使用的账号是老师提供的**公共账号**。
- AI 或自动化工具不得擅自进行以下操作：
  - 修改本项目目录以外的文件。
  - 修改系统配置。
  - 安装全局软件。
  - 影响其他用户。
- 任何涉及本项目目录以外的操作，**必须先询问用户并获得确认**。

## 3. 依赖安装

- 所有 npm / pnpm 依赖必须安装在项目目录内：

  ```text
  /home/zhuohankui/Zhenghx/Project/flower/node_modules
  ```

- 禁止：

  ```text
  npm install -g
  sudo npm install
  全局 pip install
  ```

- 开发：当前实验室服务器。
- 生产：未来独立云服务器。
